Bathroom tap maintenance requests

maintenance · overlap-maintenance-01

Residents use the maintenance board to report problems with household fixtures. A useful report describes the fixture, the room, the symptom, and when it was noticed. A clear description makes it easier for the coordinator to recognize whether several residents are reporting the same problem. Photos can be useful if the issue is visible and the resident can take them without handling the fixture. If a photo cannot be taken easily, a written description is sufficient to start a report. The household coordinator checks the board to decide what follow-up is needed and records who will handle it.

For a slow drip from the bathroom tap, open a Plumbing card on the Maintenance board. Write the room, the time you first noticed the drip, and whether it continues with the handle fully closed. Attach a photo if you can take one safely. Check for an existing card for that fixture before opening a new one, and add your observation to the existing card if it is already listed. Notify the household maintenance coordinator through that card. This is the household reporting workflow for a slow tap drip and leaves repair decisions with the coordinator.

Bathroom tap maintenance requests

maintenance · overlap-maintenance-02

For a slow drip from the bathroom tap, open a Plumbing card on the Maintenance board. Write the room, the time you first noticed the drip, and whether it continues with the handle fully closed. Attach a photo if you can take one safely. Check for an existing card for that fixture before opening a new one, and add your observation to the existing card if it is already listed. Notify the household maintenance coordinator through that card. This is the household reporting workflow for a slow tap drip and leaves repair decisions with the coordinator.

The coordinator reviews tap reports together with earlier maintenance notes for the same fixture. If a visit is planned, the coordinator records the appointment status and any access arrangements on the card. Residents add new observations to that card when the symptom changes, which keeps the account of the problem in one place. A card remains open while an inspection or repair is still pending. After the work is done, record the completion date and a short description of the result. This record helps the household distinguish a recurring issue from a new observation during future checks.
