# Chores and shared spaces

## Kitchen closing routine

The kitchen closer takes the evening handoff after the last meal. The schedule assigns one closer for each evening and lists a backup for weeks when a resident travels. Before starting, the closer checks the task board for notes about items soaking or food waiting to cool. A note should identify the item and the resident who will finish it. The closer can complete the rest of the routine while that resident handles the exception. Clean cookware belongs in the drying rack until it is dry enough to put away. Keep the main counter available for breakfast preparation.

When the evening kitchen close is finished, mark the existing Kitchen Close card complete on the household task board. If the dishwasher is running, clip the Running tag to its handle and leave unloading for the next morning. If a soaking pan remains, record the pan and its owner in the card note so the morning resident can identify it. Do not create a second closing card for the same evening. The completion note is the handoff for the next resident, even when some equipment is still occupied. The Running tag only identifies dishwasher status and does not mark the kitchen task complete.

The morning resident checks the latest completion note before unloading dishes or putting away items left near the sink. If the dishwasher has a Running tag, check that the cycle has ended before moving the tag to its storage hook. The morning task board keeps dishwasher unloading separate from kitchen closing, which lets each resident record their own work. If the note identifies a soaking pan, leave it in the named location until the assigned resident handles it. The morning resident can use the free counter to set out breakfast supplies while these remaining items are resolved.

## Shared room reset

The shared room reset begins with a quick review of the tables and seating areas. Each resident gathers their own books, chargers, mugs, and papers before wiping a shared surface. Unclaimed items go into the shared room return basket on the lower shelf, where they can be retrieved without opening private drawers. The resident doing the reset records large items that do not fit in the basket on the shared room card. The card lists the item and its temporary location. Personal papers remain face down while they wait for collection, even when the room will be used for a gathering.

A shared room reset leaves chairs and footstools clear of the walking route. Put extra cushions on the low shelf unless a resident has requested a different arrangement for the next activity. The reset card includes a place to record a loose furniture fitting or a damaged cover so the next person can plan around it. Moving furniture to make the route passable is part of the reset, but furniture repair has a separate maintenance task. When several people use the room in one evening, the last scheduled activity group is responsible for recording the final room condition.

The Sunday room review looks at whether the previous week left enough space for studying, conversation, and everyday storage. Residents can propose a different position for common items on the shared room card and try it during the next week. Keep frequently used supplies near the activity that needs them, and note any move that could make an item hard to find. The review is an opportunity to improve storage and handoffs. It does not replace the evening routine or assign a new kitchen closer. Record an agreed layout as a short note so future resets use the same arrangement.
