# Household inventory

## Borrowing and returning tools

The shared tool inventory identifies equipment that belongs to the household and its normal storage location. Small hand tools are arranged in labeled bins so a resident can tell whether a missing item is being used or was put away elsewhere. The inventory card includes the tool name, its home bin, and any accessories that travel with it. Before starting a project, check the card and confirm that the necessary pieces are present. Residents leave personal equipment in their own storage unless they have agreed to share it. This keeps household availability records meaningful for everyone.

Before borrowing the shared cordless drill, add your name, the tool name, and your expected return time to the Tool Checkout card. The drill normally lives in the blue tool bin in the hallway cupboard. Keep the drill bits with the drill while it is checked out. On return, put both the drill and the bits back in that bin and close your checkout entry. If a piece is missing, add a note to the entry before closing it so the next user can check availability. The checkout card records who has the tool while it is away from its normal location.

The household checks shared tools during the monthly cupboard review. The reviewer compares open checkout entries with the tools that are physically present and asks borrowers about entries that have passed their expected return time. Items with damaged cases or missing accessories receive an inventory note so residents can avoid relying on an incomplete kit. The review can also identify tools that are rarely used and would benefit from a clearer label. The normal locations printed on inventory cards should be updated when a bin is moved. This makes later checkout and return instructions easier to follow.

## Pantry and supply counts

Pantry counts separate sealed packages from items that are already open. An unopened package contributes one unit to the reserve count, while open packages are described in the usage note. Residents use this convention so a nearly empty container is not mistaken for a replacement. The pantry shelf labels identify the preferred location for each reserve supply. During the count, place products with earlier use dates toward the front so they are easier to notice. If the household stops buying a product, update the shelf label after the remaining packages have been used or moved.

The supply shelf uses a low-stock marker to prompt a review of recurring purchases. A resident who sees a marker checks the reserve count and considers any planned activities before adding an item to the shopping list. The marker is a reminder to check the stock, not a completed purchase or an instruction to buy a specific brand. If another resident has already added the item, use that list entry to record an updated quantity. The shelf note may identify a suitable alternative, but any store substitution still follows the approval written on the actual shopping list entry.

The linen inventory records where household towels, blankets, and spare sheets are normally stored. Residents count complete sets so a sheet without its matching pillowcases does not appear as a ready set. A shelf label shows the sizes that fit the guest bedding. If a set is temporarily drying, the inventory note records the expected return to storage. Everyday bathroom towels and reserved guest supplies are counted separately. This makes it easier to prepare a room without emptying the supplies that residents need for their regular routines. Update the count when a worn set is removed.
